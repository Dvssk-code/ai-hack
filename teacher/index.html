План занятия · как работает платформа

полный разбор для преподавателя
СТРАНИЦА КОМАНДЫ — ЧТО ВИДИТ СТУДЕНТ
  1. Студент открывает одну общую ссылку (секция 02) и выбирает карточку своей команды 1/2/3 — дальше всё на странице команды.
  2. Сверху — задание и требования жюри. Таймер ⏱ в шапке общий для всех команд: стартует после «🚀 Начать занятие» (секция 04), синхронизируется даже на уже открытых страницах.
  3. Слева — редактор (index.html / style.css / script.js). «▶ Запустить» открывает превью приложения прямо на странице — его можно потрогать с телефона, без новых вкладок.
  4. Справа — чат с нейронкой ВЕГА: описывают задачу словами → получают работающий код → кнопка «⚡ Вставить в редактор». Три такие попытки; на четвёртой ВЕГА выдаёт финальный код и отключается.
  5. «📤 Проверили, работает — отправить работу» — работа уходит на GitHub Pages. QR-код появляется на странице команды и на этом пульте через ~1 минуту, когда Pages подхватит файл.
  6. Если код вставлен не полностью — приложение само покажет «⚠️ Приложение не запустилось» и перечислит, чего не хватает. Студенту остаётся переклеить код целиком из чата.
ПЛАН ЗАНЯТИЯ — ВАШИ ШАГИ
  1. До старта — прогоните демо-стенд (секция 03): покажите классу «промт → ВЕГА пишет код → приложение запускается». Рассказ ведёте сами; стенд показывает только промты и ответы ВЕГИ.
  2. Раздача ссылок — единый QR (секция 02): студенты сканируют и выбирают свою команду.
  3. Старт — «🚀 Начать занятие» (секция 04): работы сброшены, общий таймер 15:00 пошёл. Студенты могут открывать страницы когда угодно — таймер подхватится сам.
  4. Первые минуты — команды формулируют первое описание задачи. Помогите сформулировать промт: что за объект, какие правила, что на экране, как управляется.
  5. Середина — попытки 2–3, доработка приложения. Когда работы сдаются, на пульте (секция 04) появляются QR-коды: сначала «сдана · собирается», затем «на сайте».
  6. Финал — таймер вышел: четвёртая попытка, нейронка отключена, у команд финальный код. Проверяют, отправляют. Итог — три QR-кода на пульте: сканируете и рассматриваете работы вместе с классом.
