# AI-HACK · платформа для хакатона-урока

3 команды × 2 человека. За 15 минут каждая команда собирает **мобильное веб-приложение**
вместе с нейронкой **ВЕГА**. Студенты заходят по **одной единой ссылке** — корню —
и сами выбирают команду.

## Роли страниц
| Адрес | Кто | Что |
|---|---|---|
| `https://Dvssk-code.github.io/ai-hack/` | все студенты | единая точка входа: выбор команды 1/2/3 → переход на её страницу |
| `…/ai-hack/teacher/` | препода | пульт: единая ссылка + QR команд, демо-стенд нейронки, старт занятия, QR работ |
| `…/ai-hack/1/` | команда 1 | «Змейка для двоих» (WASD + стрелки) |
| `…/ai-hack/2/` | команда 2 | «Морской бой» (против компьютера) |
| `…/ai-hack/3/` | команда 3 | «Гоночная машинка» (физика, монеты) |

## Сценарий для студентов
1. Открывают единую ссылку (на ПК продиктована, на телефоне — QR с пульта) → выбирают команду.
2. Попытки 1–3 — нейронка отвечает **через Yandex API** (личность ВЕГИ и требования задания
   идут в системном промпте, ответ парсится в HTML/CSS/JS).
3. Попытка 4 — интерфейс переключается в финальный режим: готовый код, нейронка отключается,
   команда запускает и сдаёт.
4. Сдача — `works/team{N}.html` в этом репозитории, QR у студента и на пульте препода.

## Сценарий для преподавателя (пульт `…/ai-hack/teacher/`)
1. **01 · Команды** — «ОДНА ССЫЛКА ДЛЯ ВСЕХ СТУДЕНТОВ»: URL корня + QR; студенты сами
   выбирают команду. Ниже — карточки команд с QR их страниц.
2. **02 · Демо-стенд** — «▶ Прогнать сценарий»: голос преподавателя + промты + ответы ВЕГИ
   с паузами (по скрипту, 0 токенов). Код вставляется в демо-редактор, «▶ Запустить» —
   симулятор гравитации в новой вкладке.
3. **03 · Старт занятия** — «🚀 Начать занятие»: сброс работ `works/team*.html` + запись
   `works/starts.json` — общий таймер 15:00. Страницы команд синхронизируются с ним
   (Pages подхватывает файл ~за минуту, страницы сами дожидаются и подстраивают таймер).

## Настройка (config.js)
- `ai.apiKey` — ключ Yandex Cloud (начинается с `AQVN…`), роль `ai.languageModels.user`.
- `ai.yandex.modelUri` — например `gpt://ai/cloud/b1g…/yandexgpt/latest`.
  Без ключа попытки 1–3 отвечают «нестабильная связь», 4-я — финальный код (занятие проходит).
- `github.token` — fine-grained PAT (содержимое репо → read/write). Лежит разрезанным на
  фрагменты, чтобы push protection не рвал коммиты. **После урока — отозвать токен.**

## Технически
- Статический сайт, GitHub Pages (main, корень). Сдача/сброс/старт — Contents API из браузера.
- Работы: `works/team{1,2,3}.html`, старт: `works/starts.json`.
- Файлы: `tasks.js` (задания + финальный код), `ai.js` (ВЕГА, Yandex API, парсер),
  `bot.js` (попытки + демо-сценарий), `github.js` (API), `student.js` (страница команды),
  `teacher.js` (пульт), `style.css` (платформенная тема).
