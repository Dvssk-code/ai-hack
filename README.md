# 🚀 AI-Hack — «Собери веб-приложение за 15 минут»

Три команды (по 2 человека), три задания. У каждой команды на ПК:
**слева редактор кода** (HTML/CSS/JS + кнопка «Запустить в новой вкладке»),
**справа — нейронка**. Нейронка работает по сценарию-издевательству:
1-я и 2-я попытки дают кривой код, на 3-й «переключается» в нормальную и выдаёт готовый промпт,
на 4-й — рабочее приложение. Дальше команды запускают, проверяют и **жмут «Отправить»** —
работа улетает на GitHub, а на экране преподавателя (ТВ) появляется **QR-код** работы.

## Файлы

| Файл | Кто |
|---|---|
| `index.html` | команды: выбор группы → IDE + нейронка → запуск → отправка + QR |
| `teacher.html` | преподаватель (ТВ): живые QR команд (автообновление 8 с) + **демо нейронки по скрипту** (без API) |
| `tasks.js` | 3 задания: описание, «баг-коды», финальные решения, тексты сценария, заметки для препода |
| `bot.js` | движок сценария (0 токенов) + переход на реальный API |
| `ai.js` | реальный API (OpenAI-совместимый или Yandex Cloud) |
| `github.js` | приём работ (GitHub Contents API) |
| `config.js` | **сюда вставляем API-ключ и настройки GitHub** |

## 1. API-ключ нейронки

Открой `config.js`:
```js
ai: {
  provider: "openai",
  apiKey: "ВСТАВЬ-СЮДА-API-КЛЮЧ",   // ← сюда
  openai: { baseURL: "https://api.openai.com/v1", model: "gpt-4o-mini" },
  ...
}
```
- **OpenAI / OpenRouter / Groq / LM Studio / любой OpenAI-совместимый** — впиши ключ, при необходимости `baseURL` и `model`.
- **Yandex Cloud** — `provider: "yandex"`, ключ из сервисного аккаунта, `folderId` и `model` (gpt5-latest / gigachat).

Пока ключ не вписан — всё равно работает: сценарий не тратит токены, а на вопросы «за рамками» бот отвечает: «ключ не подключён».
**По минимуму**: весь путь «кривой код → промпт → рабочее приложение» отыгрывается локально, API вызывается только после,
когда команды начинают дорабатывать/чинить.

## 2. GitHub (куда падают работы + откуда жрёт QR)

1. Создай публичный репозиторий, например `hack-works`.
2. В репозитории создай **пустую папку `works/`** (добавь файл `works/.gitkeep`) и запушь.
3. Включи **GitHub Pages** (Settings → Pages → Deploy from branch → main, корень `/`).
   Готовый URL вида `https://{owner}.github.io/hack-works/` впишешь ниже.
4. Создай **fine-grained Personal Access Token**:
   - доступ: только этот репозиторий;
   - права: **Contents: Read and write** (ничего больше не нужно).
5. В `config.js` впиши:
```js
github: {
  owner: "твой-логин",
  repo: "hack-works",
  token: "github…здесь",
  pagesBase: "https://твой-логин.github.io/hack-works/"
}
```

Как это работает: «📤 Отправить» кладёт собранный HTML в `works/team{N}.html` через GitHub API,
QR ведёт на `https://{owner}.github.io/hack-works/works/team{N}.html` — чистый публичный Pages-URL.

⚠️ **Честно про токен**: это клиентское приложение, токен виден в исходниках страницы любому.
Для занятия это ок (fine-grained, один репозиторий, только Contents), но **после события токен отозвать**
(Settings → Tokens → Revoke). API-ключ — та же история: для учебного занятия ок, но ставь на него лимит расходов.

## 3. Размещение самого сайта

Запушь папку `ai-hack` в отдельный репозиторий (например `ai-hack-site`) и включи Pages —
команды заходят по ссылке `https://{owner}.github.io/ai-hack-site/`.
(Или просто раздай папку на ПК — всё работает и офлайн, кроме GitHub-отправки.)

## 4. Ход занятия (≈35 минут)

| Время | Что |
|---|---|
| 0–3 мин | Препода открывает `teacher.html` на ТВ, жмёт «▶ Прогнать демо» — класс видит весь сценарий нейронки. Назначает команды: группа 1 → змейка, 2 → мемори, 3 → мем-генератор |
| 3–18 мин | Команды работают. Нейронка издевается → выдаёт промпт → рабочее приложение. Команды вставляют, запускают (▶ в новой вкладке), чинят мелочи (тут уже тратятся API-токены — по минимуму) |
| 18–22 мин | «📤 Отправить» → работы на GitHub → на ТВ появляются 3 QR |
| 22–35 мин | Жюри/класс открывает QR на телефонах и тестирует руками. Приз за «самое живое» и «самое смешное» 🏆 |

**План Б**: если GitHub/инет лег — на странице сдачи появится сообщение и работа скачается файлом `work_team{N}.html`,
препода просто открывает файл. Сценарий нейронки и редактор работают полностью офлайн.

## Сценарий нейронки (как устроено)

- `tasks.js` хранит у каждого задания 3 версии кода: `v1` (баги намеренные и смешные — например, у змейки стрелка ВВЕРХ ведёт ВНИЗ), `v2` (почти готово) и `final` (рабочее решение).
- `bot.js` — конечный автомат: попытка 1 → v1, попытка 2 → v2, попытка 3 → «я другая нейронка, вот промпт», попытка 4 → final, дальше → реальный API.
- **Если команда сразу пишет отличный промпт** (длинный, с конкретикой) — бот «в шоке» и выдаёт рабочее приложение сразу. Для смеха и поощрения.
- В демо-режиме (teacher.html) API никогда не вызывается, у ответов показываются «заметки препода» (что подсказать в этот момент).

## Частые вопросы

- **QR не открывается сразу после отправки?** GitHub Pages пересобирает ~1 минуту. На экране сдачи это учтено текстом.
- **Команда пересдала работу?** Просто жмёт «Отправить» ещё раз — файл перезаписывается, QR тот же.
- **Хочется другой сценарий/задания?** Всё в `tasks.js`: тексты `tease1/tease2/revealText/finalText`, код `v1/v2/final`, заметки `note1..4`.
- **Хочешь 4-ю команду?** Добавь задание в `tasks.js` (group: 4) — сетка групп и панель подхватят сами.
